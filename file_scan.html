Detection Modules

01 / HASH
Cryptographic Signatures
MD5, SHA1 & SHA256 fingerprinting for unique file identification and known-malware database matching.
02 / ENTROPY
Shannon Entropy Analysis
Detects encryption, packing, and obfuscation by measuring randomness in the byte distribution.
03 / MAGIC
Magic Byte Detection
Reads file headers to detect true file type. Flags extension mismatches used to disguise executables.
04 / PATTERNS
Behavioral Pattern Scan
Scans for 30+ malicious code signatures: ransomware, backdoors, webshells, keyloggers, and RATs.
05 / VIRUSTOTAL
Cloud Threat Intel
Cross-references file hash against 70+ antivirus engines via the VirusTotal API for known threat detection.
06 / RISK
Dynamic Risk Scoring
Weighted scoring across all signals produces a 0–100 risk score with 5 threat levels: Clean to Critical.
